# JavaScript desde cero

Repositorio de mis apuntes y ejercicios mientras aprendo los
fundamentos de JavaScript. El contenido se actualiza conforme
avanzo en el curso.

## Temas

- Variables y tipos de datos.
- Operadores y cadenas de texto.
- Condicionales.
- Arrays, sets y maps.
- Bucles.
- Funciones.
- Objetos, propiedades y métodos.

## Organización

La carpeta `Basic/` contiene los ejercicios numerados por tema,
desde el primer «Hola mundo» hasta el trabajo con objetos.

## Cómo ejecutar los ejercicios

Necesitas tener Node.js instalado.

Clona el repositorio y entra en la carpeta:

```bash
git clone https://github.com/daniel43-cod/javascript-desde-0.git
cd javascript-desde-0
```

Ejecuta el archivo que quieras practicar:

```bash
node Basic/12-objets.js
```

Cada archivo se ejecuta de forma independiente.
No necesitas instalar dependencias.
